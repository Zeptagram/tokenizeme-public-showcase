# Contributing

Thank you for your interest in improving the TokenizeMe public showcase.

## Scope

This repository accepts contributions that are safe for a public audience:

- documentation improvements
- public example code
- diagrams and architecture clarifications
- developer-experience improvements
- sanitized API examples

This repository does not accept:

- production credentials or environment details
- private deployment scripts
- sensitive infrastructure references
- proprietary business logic copied from private systems

## How to contribute

1. Fork the repository
2. Create a focused branch
3. Make changes with clear commit messages
4. Open a pull request with context and screenshots if relevant

## Review guidelines

- keep examples minimal and easy to understand
- prefer security-safe placeholders over speculative internals
- document assumptions when describing workflows
- avoid adding dependencies unless they materially improve the public showcase
